Give a short explanation of doctype, html, head, body. title, element, tag, attribute, nesting, and void element.

Doctype is a tag/declaration in html that tells the browser what type of document to expect, it simply just shows the type of document.
html tag serves as a container for all other element in the HTML code except the Doctype tag. It defines the root of the HTML document/page.
Head tag contains the metadata (data about the data in the document) and links for the document. It is not displayed on the page.
Body tag defines the body of the document. it contains all the content of the documents such as the headings, paragraphs etc.

Title tag defines the title of the document, it is text-only and it is shown in the page's tab. It is important for search engine optimization (SEO) which is used by search engine algorithms to decide the order when listing pages in search results.
Element in html is defined by a start tag and for some, an end tag. They are basic building blocks of a webpage, they define the structure and content using the start and end tags and the intended content.
Tag is simply a piece of code used to tell the web browser how to structure and display content of a webpage.

Attribute provide additional information about elements and they are always specified in the start tag. example lang, charset, name etc. They alaways have a value attached to them.
Nesting means putting children elements into a parent element. Example, the body element that is nested within the html element.
Void element is an element that cannot have any nested or text nodes. They only have start tags and it is important they do not have end tags.
